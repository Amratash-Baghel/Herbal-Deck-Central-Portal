# Working rules (from the owner — always follow)

- List assumptions first; stop and ask if anything is unclear.
- Write the minimum: nothing that wasn't asked for. If 200 lines could be 50, rewrite them.
- Only touch the lines the change needs.
- For a bug: write a test that reproduces it, then make it pass.
- If a change will be large, ask before starting, not after.
